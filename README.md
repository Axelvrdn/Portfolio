# Axel Verdon — Portfolio

Portfolio from scratch: an original editorial and interactive experience inspired by the quality of aengel.io, not a copy of its layout, assets, text, or identity.

## Stack

- Astro static output
- TypeScript content model
- CSS-first motion and progressive enhancement
- Optional future hero canvas, never required for reading
- Docker staging
- Cloudflare Workers Static Assets production

## Commands

```bash
npm install
npm run dev
npm run build
npm run cf:dry-run
```

Staging target: `pc-lab`, port `8210`. Production deployment requires explicit approval.
